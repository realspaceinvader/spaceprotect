# Security Policy / Sicherheitshinweise

## Reporting a vulnerability / Sicherheitslücke melden

**EN:** Please do **not** open a public issue for security problems. Use GitHub's
"Report a vulnerability" (Security → Advisories) on this repository, or contact the author via
[spaceinvader.at](https://spaceinvader.at). Please include the Spaceprotect version, Windows version and
steps to reproduce.

**DE:** Bitte für Sicherheitsprobleme **kein** öffentliches Issue anlegen. Nutze auf GitHub
„Report a vulnerability“ (Security → Advisories) oder kontaktiere den Autor über
[spaceinvader.at](https://spaceinvader.at). Bitte Spaceprotect-Version, Windows-Version und die Schritte zur
Reproduktion angeben.

## Scope / Geltungsbereich

Spaceprotect protects against a **standard user** (for example a child) changing limits, stopping the
background process or editing the data. It does **not** protect against local administrators, physical access
or booting another operating system. Details are in the README.

Spaceprotect schützt vor einem **Standardbenutzer** (zum Beispiel einem Kind), der Limits ändern, den
Hintergrundprozess stoppen oder die Daten bearbeiten will. Es schützt **nicht** vor lokalen Administratoren,
physischem Zugriff oder dem Start eines anderen Betriebssystems. Details stehen in der README.
